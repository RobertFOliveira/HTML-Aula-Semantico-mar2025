Modelo de Div

A tag

do HTML é um elemento que define uma seção ou divisão em um documento. É um contêiner genérico que pode agrupar diferentes tipos de conteúdos, como imagens e texto. A tag
é muito utilizada para construir layouts de páginas web. Ela pode ser estilizada com o uso do CSS.

> A tag
